🎯 RAG Pipeline สำหรับ Monolith

  • Step 1: Enable pgvector extension ใน Supabase project
  • Step 2: Parse daph-second-brain/_knowledge-export.json → chunk เป็น process step + PFMEA row แต่ละ record
  • Step 3: Embed ด้วย OpenAI Embeddings API (text-embedding-3-small = $0.02/1M tokens)
  • Step 4: Store ใน knowledge_documents table ที่มี embedding vector(1536) column
  • Step 5: สร้าง match_documents RPC (TypeScript pattern ใน Supabase แล้ว)
  • Workflow Copilot Req 19 (Knowledge Query Tool): ใช้ RPC นี้ผ่าน MCP Read_Tool
