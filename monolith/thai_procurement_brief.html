1. กรอบ RFP-GAP05-001

S51 · 51.4
บริบท: GAP-05 (AI Creative Engine) เป็นช่องว่างสำคัญระดับ Phase 2 — ยังไม่มีระบบ AI สำหรับการสร้างแนวคิดงานออกแบบโดยอัตโนมัติ ทำให้ Agent ต้องพึ่งพาการสร้าง brief และ mood board ด้วยมือ ส่งผลให้เวลาส่งมอบล่าช้า 30–40% ต่อโครงการ
รหัสเอกสาร รายการ รายละเอียด กำหนดการ
RFP-GAP05-001 Request for Proposal — AI Creative Engine ระบบ AI 5 โมดูล (AIE-001–005) สำหรับ Creative Workflow อัตโนมัติ ออก RFP: P2-M1+2สัปดาห์
PQ-GAP05-001 Pre-Qualification Questionnaire คัดกรองคุณสมบัติเบื้องต้น: ประสบการณ์ AI Generative Design ≥3 ปี ปิดรับ: RFP+2สัปดาห์
SOW-AIE-001 Statement of Work — AIE-001 Concept Generator ผลิต concept variants จาก project brief; latency ≤3s p95 แนบ RFP วันออก
SOW-AIE-002 Statement of Work — AIE-002 Style Harmoniser Mapping style taxonomy ตาม MONOLITH style library v2.5; ≤5s p95 แนบ RFP วันออก
SOW-AIE-003 Statement of Work — AIE-003 Material Specifier อ้างอิง SKU จาก approved supplier catalogue; webhook push model แนบ RFP วันออก
SOW-AIE-004 Statement of Work — AIE-004 Mood Board Assembler Batch API รวม output AIE-001–003; ผลิต PDF + asset bundle; ≤30s แนบ RFP วันออก
SOW-AIE-005 Statement of Work — AIE-005 Client Presentation Renderer Streaming API; HTML5 interactive; ≤60s first render; export 300dpi แนบ RFP วันออก
DPA-GAP05 Data Processing Agreement PDPA compliance; ประมวลผลในประเทศไทยหรือเขตอำนาจที่ได้รับอนุมัติ แนบสัญญาหลัก

3. เกณฑ์การประเมินผู้ขาย

S51 · 51.3
40%
Technical Score
  • สมรรถนะ AI/ML สำหรับ Generative Design
  • Architecture ที่ scale ได้ (50+ concurrent)
  • Latency SLA ตาม AIE-001–005 spec
  • Integration กับ MONOLITH API Gateway v2.5
  • Security: ISO 27001; TLS 1.3; OAuth 2.0
30%
Commercial Score
  • ราคารวม AIE-001–005 ≤ THB 1.5M
  • โครงสร้าง payment milestones
  • เงื่อนไขการรับประกันและ SLA penalty
  • TCO 3 ปี (license + support + upgrade)
  • ความยืดหยุ่นในการเจรจาสัญญา
30%
Strategic Score
  • ประสบการณ์งาน Interior/Hospitality Design
  • Portfolio ลูกค้าอ้างอิงในอุตสาหกรรม
  • Roadmap ผลิตภัณฑ์ 3 ปีที่สอดคล้องกับ Phase 3
  • ความพร้อมทีม Support ในประเทศไทย
  • ความมั่นคงทางการเงิน (Dun & Bradstreet)

4. SLA KPIs สำหรับ AIE-001–005

S51 · 51.6
โมดูล ชื่อโมดูล Latency (p95) Availability Error Rate สูงสุด ผู้ติดตาม SLA
AIE-001 Concept Generator ≤ 3 วินาที ≥ 99.5% ≤ 0.5% Nova + Signal
AIE-002 Style Harmoniser ≤ 5 วินาที ≥ 99.5% ≤ 0.5% Nova + Signal
AIE-003 Material Specifier ≤ 10 วินาที ≥ 99.0% ≤ 1.0% Nova
AIE-004 Mood Board Assembler ≤ 30 วินาที ≥ 99.0% ≤ 1.0% Nova
AIE-005 Client Presentation Renderer ≤ 60 วินาที ≥ 99.0% ≤ 2.0% Nova + Aria
SLA Penalty Schedule
  • Availability < 99.5% ในเดือนใด: service credit 5% ของค่า license เดือนนั้น
  • Availability < 98.0%: service credit 15%; right to escalate to SC
  • Availability < 95.0% ติดต่อกัน 2 เดือน: สิทธิ์บอกเลิกสัญญา
  • Latency เกิน SLA > 5% ของ requests ในเดือน: service credit 3%
KPI Monitoring — Nova Dashboard
  • Real-time availability tracking ทุก AIE module
  • Latency percentile charts: p50, p95, p99
  • Error rate monitoring พร้อม alert threshold
  • รายงาน SLA compliance รายเดือนต่อ SC
  • Hypercare period: enhanced 30-min reporting cycle
