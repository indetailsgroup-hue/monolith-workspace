# แผนดำเนินการ P0-11

เจ้าของอนุมัติให้ session นี้สร้าง

เป้าหมาย: จัดการ whitespace ของเหตุผลการส่งล้มเหลวให้ตรงกับ str.strip() ของ Python

โครงสร้าง: migration 0197 แก้เฉพาะ normalization ของฟังก์ชันบันทึกผล ใช้ btrim กับชุดอักขระ 29 ตัว คง signature การตรวจสิทธิ์ fencing retry เวลา และการปิดบัง token

1. เพิ่ม pgTAP ผ่าน RPC จริง 37 กรณีต่อจาก 70 กรณีเดิม เก็บ RED บน stack ใหม่
2. สร้าง 0197 คง Python assertion เดิม รัน pgTAP, claim แข่งสอง client และ Python ที่จำเป็น 12 ไฟล์บน stack ใหม่อีกชุด
3. เก็บคำสั่ง เวลา UTC hash source exit code การเก็บกวาดและ checksum ไม่แก้หลักฐานเก่า ตรวจรหัสลับที่สร้างก่อน commit
4. ปรับ PRD สองภาษาและสร้าง HTML ด้วย renderer ของ repo โดยยังรอตรวจรับข้ามค่าย

ข้อจำกัด: ไม่เข้าถึง stack ที่แชร์ ไม่ให้ cron ทำงาน ไม่แก้ manufacturing ไม่ push deploy หรือส่งข้อความจริง P0-10 ยังไม่อนุมัติ คาดว่าเทสต์สิทธิ์ 8 ข้อยังล้ม เลขข้อเสนอเลื่อนไป 0198 ใช้ image postgres/auth/storage ที่มีในเครื่องกับ network แยกเฉพาะงานและเปิดพอร์ต DB บน loopback เท่านั้น (Docker Desktop ไม่เปิดพอร์ตของ internal network)
