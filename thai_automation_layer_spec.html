Event Flow — ตัวอย่าง Sale → Designer Handoff
[1] Sale Agent → MCP Tool: handoff_to_designer(brief_payload)
[2] MCP Layer → POST /webhook/agent-event
    body: { event: "brief_received", dept: "designer", payload: {...} }
[3] FastAPI webhook_handler.py → ตรวจสอบ signature → route ไป line_notifier.py
[4] flex_builder.py → สร้าง Flex Message "Brief ใหม่รอ Approve"
[5] LINE Messaging API → ส่ง message ไป LINE_GROUP_DESIGNER
[6] scheduler.py → ตั้ง reminder 20h (เตือนก่อน 4h)
[7] ถ้าครบ 24h ไม่มีการ approve → escalate ไป PM Group

ขั้นตอน Setup LINE Messaging API (Internal Bot)
  • 1
    สร้าง Provider บน LINE Developers Console

    ไปที่ developers.line.biz → Create Provider → ตั้งชื่อ "DAPH Decor MONOLITH" → บันทึก Provider ID

  • 2
    สร้าง Messaging API Channel

    ใน Provider → Create Channel → เลือก "Messaging API" → กรอก Channel name: "MONOLITH Bot", Category: "Business Services" → Create

    Channel name : MONOLITH Notification Bot Description : ระบบแจ้งเตือนภายใน DAPH Decor - MONOLITH AI Agent System Category : Business Services Subcategory : Consulting Services
  • 3
    เปิดใช้งาน Messaging API Settings

    ใน Channel → Messaging API tab → เปิด settings เหล่านี้:

    Settingค่า
    Auto-reply messages❌ Disabled
    Greeting messages❌ Disabled
    Webhook✅ Enabled
    Allow bot to join group chats✅ Enabled
  • 4
    บันทึก Credentials

    จด 3 ค่านี้ไว้ใน .env ของ FastAPI:

    # LINE Messaging API — Internal Bot LINE_CHANNEL_SECRET=<ค่าจาก Basic Settings → Channel secret> LINE_CHANNEL_ACCESS_TOKEN=<ค่าจาก Messaging API → Channel access token> # กด "Issue" ถ้ายังไม่มี token
  • 5
    ตั้ง Webhook URL

    ใน Messaging API → Webhook settings → Webhook URL:

    https://api.monolith.daph.co.th/webhook/line # หรือ Supabase Edge Function URL: https://<project-ref>.supabase.co/functions/v1/line-webhook

    กด Verify — ต้องได้ HTTP 200 ถึงจะ save ได้ (FastAPI ต้องรันอยู่ก่อน)

  • 6
    Add Bot เข้า Department LINE Groups

    แต่ละ Group Chat ของแผนก → เพิ่ม Bot เป็นสมาชิก → Bot จะส่ง event join มาพร้อม groupId

    # Event ที่ได้เมื่อ Bot เข้า group: { "type": "join", "source": { "type": "group", "groupId": "Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" } } # บันทึก groupId นี้ไว้ใน .env ตามแผนก
  • 7
    บันทึก Group IDs ทุกแผนก
    LINE_GROUP_SALE=Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx LINE_GROUP_DESIGNER=Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx LINE_GROUP_PM=Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx LINE_GROUP_FACTORY=Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx LINE_GROUP_PROCUREMENT=Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx LINE_GROUP_INSTALL=Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  • 8
    ทดสอบ Push Message
    import os from linebot.v3.messaging import Configuration, ApiClient, MessagingApi from linebot.v3.messaging.models import PushMessageRequest, TextMessage config = Configuration(access_token=os.environ["LINE_CHANNEL_ACCESS_TOKEN"]) with ApiClient(config) as api_client: api = MessagingApi(api_client) api.push_message(PushMessageRequest( to=os.environ["LINE_GROUP_SALE"], messages=[TextMessage(text="✅ MONOLITH Bot พร้อมใช้งานแล้ว")] ))
LINE Official Account Setup (Customer Channel)
  • 1
    สร้าง LINE Official Account

    ไปที่ account.line.biz → Create → กรอกข้อมูลบริษัท DAPH Decor → รอ verify (1–3 วันทำการ)

  • 2
    เชื่อม LINE OA กับ Messaging API Channel

    LINE OA Manager → Settings → Messaging API → Link to Messaging API Channel → เลือก Channel ที่สร้างใน Step 2 ข้างบน

    หลังจาก Link แล้ว LINE OA และ Messaging API จะใช้ Channel Access Token เดียวกัน — Bot ส่ง message ได้ทั้ง internal groups และ customer push message
  • 3
    รับ userId ลูกค้า

    เมื่อลูกค้า add LINE OA เป็นเพื่อน → Bot ได้รับ follow event พร้อม userId → บันทึกลง Supabase customers table

    # Supabase: customers table { "customer_id": "CUST-2026-0042", "line_user_id": "Uxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx", "display_name": "คุณสมชาย ใจดี", "added_at": "2026-09-04T10:00:00Z" }
  • 4
    ตั้ง Rich Menu (optional แต่แนะนำ)

    LINE OA Manager → Rich Menu → สร้าง menu สำหรับลูกค้า เช่น "ดูสถานะงาน | นัดหมาย | ติดต่อ Sale" — ช่วยลด inbound message ที่ต้อง handle

# FastAPI Service — Automation Layer services/ __init__.py webhook_handler.py # รับ POST จาก MCP + ตรวจ signature LINE line_notifier.py # push message ไป LINE Groups line_oa.py # push message ลูกค้าผ่าน LINE OA flex_builder.py # สร้าง Flex Message JSON per event scheduler.py # APScheduler — remind + escalate line_signature.py # verify X-Line-Signature
webhook_handler.py
