UAT Phase E — User Acceptance Testing สำหรับ 5 MVP Agents

ทดสอบ AI Agents ทั้ง 5 ตัวด้วย KPI benchmarks และ test cases ที่ derive จาก PFMEA Risk Controls เงื่อนไข: ทุก Agent ต้องผ่าน score ≥3.0 เฉลี่ย และไม่มี Critical Fail ก่อน Gate-1 จะเปิด

Sale Agent Designer Agent Factory Agent PM Agent Procurement Agent

📊 Evaluation Rubric — 4-Level Scoring System

✅ Pass 4
ตรงหรือเกิน KPI target ทุกข้อ ไม่มี critical failure ใดๆ พร้อม production ทันที
🔵 Satisfactory 3
ค่าเบี่ยงเบนเล็กน้อยจาก target ไม่มี blocking issue สามารถ deploy ได้ โดยมีการ monitor เพิ่มเติม
⚠️ Needs Improvement 2
ค่าเบี่ยงเบนมีนัยสำคัญ หรือมี recurring issues ต้องแก้ไข prompt/logic ก่อน deploy
❌ Fail 1
ไม่บรรลุ KPI หลักหรือมี critical failure บล็อก UAT progression ห้าม deploy
🏁

Gate-1 Requirement: ทุก Agent ต้องผ่าน Score ≥ 3.0 (Average) ก่อน Gate-1 เปิด

หาก Agent ใดได้ Score = 1 ในมิติ Critical (Safety/Accuracy/Halt) → UAT ถือว่า Fail ทันที ไม่ว่า score มิติอื่นจะเป็นเท่าใด
