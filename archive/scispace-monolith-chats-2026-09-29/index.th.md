## การตรวจไฟล์

manifest.json ระบุจำนวนตัวอักษรและ SHA-256 ของต้นฉบับแต่ละแชต checksums.sha256.json ใช้ตรวจไฟล์ฉบับอ่านทั้งหมด หลักฐาน raw เก็บแยกในโฟลเดอร์งานและไม่รวมใน ZIP ฉบับอ่าน.

เอกสารนี้จัดเก็บใน governance/bootstrap root ส่วน product source อยู่ใน determined-williams/ ซึ่งเป็น Git repository แยก งานนี้ตรวจ Git status ทั้งสอง root และไม่แก้ไข product source ไม่ใช้ข้อความเก่าเป็นข้อสรุป current state ของผลิตภัณฑ์.
